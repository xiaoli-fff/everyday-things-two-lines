Two lines explaining an echo to a ten-year-old: shouting hello into a deep well and hearing it shout back — sound bouncing like a ball, except nobody is answering; it is only your own voice, tired from the trip.

## Run it

```sh
node main.ts
```

The program writes the two lines to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
